Importação em Bloco

Se a linha tiver só o link, o nome é deduzido do nome do arquivo da imagem (ex.: .../Pizza-Slice.webp → Pizza Slice). Arquivos tipo image.png ou IMG_2043.jpg não dão nome — o item entra como "Imported Item N" e recebe o nome sozinho depois, sempre que der (ao abrir o app e ao sincronizar o catálogo). O botão abaixo força essa renomeação na hora.

🪄 Parser Automático de Rascunho

Cole abaixo o rascunho de texto com as mudanças (uma por linha). O sistema identifica sozinho Novos Itens, Aumento/Queda de Valor, Mudança de Demanda e Mudança de Status — já atualiza o banco de dados dos itens encontrados pelo nome e publica uma nova versão pronta no Changelog.

Padrões reconhecidos (uma linha por mudança):
• Nome set to 150, Range [130-170], 4 stars, Fluctuating → Novo Item
• Nome increased to 700 / Nome decreased to 55 → Valor
• Nome increased to 2.5 stars → Demanda
• Nome set to Doing Well → Estabilidade
• Nome labeled to Overpaid For → Selo de Status
Vários nomes na mesma linha: separe com , ou &.
